# P4 implementation plan, 2026-10-20

Owner accepted P3 and approved the two-stage design. Implementation/offline
validation is authorized; full-run model calls require separate owner approval.

## Files and design

- experiments/config.py, docs/SPEC.md: frozen stage schedules (560 stage-1 and
  280 stage-2 requests), subset seed 1729, block timing and drift rules.
- src/prompt_energy/full_run.py: staged interleaving, explicit run approval,
  preflight/runtime checks, journaling, saved-response recovery and one block per
  invocation. Reuse P2 request/evaluation and HWiNFO parser, never CodeCarbon.
- src/prompt_energy/full_energy.py: total and post-load gross/net only, block
  start/end idle records, signed drift and missing-baseline flags. Separate
  append-only measurements; derived CSV joins block flags without rewriting raw.
- experiments/run_p4.py: safe default prepare, preflight, run-block and report.
- analysis/full_analysis.py: stage-1-only group summaries and bootstrap CIs,
  verified yield (energy/tokens per correct answer), Pareto plot, per-model
  input/output-token regression with residual plots, stage-2 repeat-noise
  summaries. Both all-available and primary low-resolution sensitivity views.
  Optional owner-supplied frozen difficulty/length maps; omit P0 in group-wise
  outputs, never infer calibration groups from scored outcomes.
- tests/test_p4.py, tests/test_full_analysis.py: fake sensor/clock/API blocks,
  approval, interruption, no-op resume, start/end baselines, missing end/drift,
  excluded pilot/smoke, statistical edge cases and source-data immutability.
- README overnight guide and docs/learning/P4.md with five questions/assumptions.

Owner-approved timing: stop launching after 3 h, finish active call, ceiling 4 h.
Use monotonic elapsed for limits. Reserve time for end baseline/control cleanup;
HTTP calls remain bounded by the existing 300 s timeout. No automatic next block.
Each block measures 60 s idle at start/end after models are unloaded and a 5 s
gap; net uses start baseline. Drift flag: abs(end-start)>max(1 W,10% start).
If interrupted, keep prior answers, mark missing end baseline rather than invent
it; a new block gets its own baseline. Sensor/transport faults stop new requests.
User Ctrl+C is propagated after best-effort end-baseline cleanup when safe.

Stages are sequential, independently shuffled seed 1729; stage 1 repeats=1,
stage 2 repeats=2,3 on 10 frozen tasks. Stage 1 supplies hypothesis scaffolds;
stage 2 supplies noise diagnostics, not extra weight in hypothesis summaries.
No prompts, tasks or settings are chosen from outcome quality. Gross/net and
all failed rows remain visible; missing energy is not zero. No phase attribution.

## Risks and research decisions

Owner approved 60 s endpoints, start-baseline correction, drift threshold and
subset selection/separation. Live authorization is still absent. Calibration
labels and reference-length threshold are not supplied: scaffolds accept a
frozen map, validate provenance/IDs and report unavailable groups, with no
calibration inference or new requests. Bootstrap is task-level, seeded 1729,
2,000 draws and percentile 95% intervals, descriptive with small sample limits.
Any unresolved statistical choices must be exposed as scaffold settings for
owner review before the full run, never retrospectively tuned.

Resume must fail closed on unknown request intent, changed registration, changed
runtime/digests, duplicates and malformed journals. Preserve unavailable energy
with flags. A clean complete resume makes zero requests. Fake clocks only for
verification; no real baseline, warm-up or inference is run during implementation.

## Verification and assumptions

Small commits: registration; runner/energy/tests; analysis/docs/tests. Run full
pytest and Ruff. Assume HWiNFO 500 ms CSV, fixed UTC offset, AC/Best performance,
owner disables Windows sleep and closes other workloads. Do not alter Windows
power settings automatically. Show exact guide and stop for owner review before
any full run. Blocks may end early on exhaustion/failure; 4 h is a safety ceiling,
not a guarantee across OS suspension. Log elapsed overrun and clock discrepancies.
